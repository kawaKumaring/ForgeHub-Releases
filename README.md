# ForgeHub 배포

통합 런처와 검증된 창작 도구의 Windows 배포 파일만 제공합니다. 개발 소스·AI 모델·개인 설정은 이 저장소에 업로드하지 않습니다.

[다운로드](https://github.com/kawaKumaring/ForgeHub-Releases/releases) · [홈페이지](https://forgehub-913.pages.dev/)

각 릴리스의 검증 범위와 제한을 확인하세요. 도구의 EXE·BAT 독립 실행을 유지합니다. 모델은 사용자가 선택한 원래 위치에서 등록하며 별도로 배포하지 않습니다.

별도 허가 없이 프로그램을 재배포하거나 소스를 공개하는 권한을 부여하지 않습니다. 함께 배포하는 제3자 구성요소는 각 라이선스를 따릅니다.
